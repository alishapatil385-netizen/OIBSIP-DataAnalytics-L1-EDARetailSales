# OIBSIP-DataAnalytics-L1-EDARetailSales

# EDA on Retail Sales Dataset

## Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to uncover sales trends, customer behavior, and product performance. The analysis helps in understanding business insights through data visualization and statistical summaries.

## Objectives

* Clean and preprocess the dataset.
* Analyze sales performance across different product categories.
* Understand customer demographics and purchasing behavior.
* Identify trends and patterns in retail sales.
* Create visualizations to support business decision-making.

## Dataset Information

The dataset contains the following attributes:

* Transaction ID
* Date
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price per Unit
* Total Amount

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / VS Code

## Analysis Performed

* Data Cleaning
* Missing Value Check
* Descriptive Statistics
* Sales Trend Analysis
* Customer Demographics Analysis
* Product Category Analysis
* Data Visualization

## Key Insights

* Identified top-performing product categories.
* Analyzed customer purchasing patterns by age and gender.
* Observed sales distribution and revenue trends.
* Highlighted important business insights through visualizations.

## Conclusion

This project demonstrates the use of Exploratory Data Analysis techniques to transform raw retail sales data into meaningful insights that can support business decisions.
